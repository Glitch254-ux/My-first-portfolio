# My First Full-Stack Portfolio

This is my very first web development project! It features a professional frontend and a Node.js backend to handle messages.

## 🚀 Features
- **Frontend:** Built with HTML, CSS, and JavaScript.
- **Backend:** Node.js engine for handling form submissions.
- **Responsive:** Designed to look good on all devices.

## 🛠️ How to run locally
1. Clone the repo.
2. Run `npm install` to get the dependencies.
3. Run `node backend/server.js` to start the engine.
